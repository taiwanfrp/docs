本篇以最常見的 **Minecraft 伺服器** 為例，帶你完成內網穿透的前兩步：

::div{class="ps-6"}
1. [註冊帳號](#註冊帳號)
2. [建立隧道](#建立隧道)
::

## 註冊帳號

::steps{level="3"}

### 前往官網

開啟 [TaiwanFRP 官網 :icon{name="i-lucide-external-link"}](https://taiwanfrp.me/){target="_blank"}，點擊「註冊」。

![TaiwanFRP 官網首頁的註冊按鈕](/images/getting-started/register-01-homepage.jpg)

### 填寫帳號密碼並加入 Discord 群組

在註冊頁面填寫「使用者名稱」與「密碼」。

註冊時還需要驗證碼，而驗證碼要從官方 Discord 群組取得。點擊「進入Discord獲取驗證碼」，加入 TaiwanFRP 官方 Discord 群組。

::note
一個 Discord 帳號只能註冊一個 TaiwanFRP 帳號。
::

![註冊頁面的帳號密碼欄位與 Discord 群組連結](/images/getting-started/register-02-join-discord.jpg)

### 取得驗證碼

加入群組後，進入「註冊使用者帳號-獲取驗證碼」頻道，點擊機器人訊息下方的「點擊我」按鈕。

![Discord 的獲取驗證碼頻道](/images/getting-started/register-03-get-code-channel.jpg)

**TAIWANFRP機器人** 會把驗證碼 **私訊** 給你。複製收到的驗證碼，也可以點擊「純文字來複製驗證碼」，方便在手機上複製。

![TAIWANFRP機器人私訊的驗證碼](/images/getting-started/register-04-bot-dm.jpg)

### 完成註冊

回到註冊頁面，將驗證碼貼到「驗證碼」欄位，並點擊「註冊」。

![在註冊頁面貼上驗證碼](/images/getting-started/register-05-submit.jpg)

註冊完成後會自動回到首頁，這是正常的。

::

## 建立隧道

::steps{level="3"}

### 開啟隧道管理

登入後，點擊首頁右上角的「編輯我的隧道」。

![編輯我的隧道按鈕](/images/getting-started/tunnel-01-edit-tunnels.jpg)

### 新增隧道

剛註冊的帳號還沒有任何隧道，點擊左下角的「新增隧道」建立第一條隧道。

![新增隧道按鈕](/images/getting-started/tunnel-02-add-tunnel.jpg)

### 填寫隧道設定

依照下表填寫欄位：

| 欄位 | 填寫內容 |
| --- | --- |
| 隧道名稱 | 容易辨識的名稱 |
| 本地 IP | `127.0.0.1`，不確定用途的話請保持預設值 |
| 本地端口 | `25565`（Minecraft Java 版預設端口） |
| 遠程端口 | 別人連入時使用的端口。在欄位提示的範圍內任選，衝突就換一個 |
| 節點 | 選擇你喜歡的節點（若不確定該選哪個，可前往 [推薦最佳節點 :icon{name="i-lucide-external-link"}](http://taiwanfrp.ddns.net:8000/whatmybestchooise.html){target="_blank"}） |

::note
每個節點開放的遠程端口範圍不同。選擇節點後，「遠程端口」欄位的灰色提示文字會顯示該節點可用的範圍，請以提示為準。
::

::tip
Minecraft 基岩版的預設端口是 `19132`。架設其他服務時，本地端口請改成該服務使用的端口，例如網頁伺服器為 `80`、SSH 為 `22`。
::

![隧道設定表單](/images/getting-started/tunnel-03-form.jpg)

::warning
填寫完畢後，**一定要點擊右下角的「保存」**，否則剛才的設定都不會生效！
::

### 確認隧道已建立

保存後回到首頁。如果在「我的隧道狀態」中看到剛才建立的隧道，就代表建立成功了。

![我的隧道狀態中出現新建立的隧道](/images/getting-started/tunnel-04-created.jpg)

::note
此時 TCP、UDP 狀態顯示「離線」是正常的，因為還沒有啟動客戶端。
::
